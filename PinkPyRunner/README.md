# PinkPy Runner

A pink-themed Android Python runner using Chaquopy. The APK bundles CPython 3.13 and is configured for arm64-v8a, covering current ARM64 Android phones/tablets and Meta Quest compatibility mode.

## Features
- Select a .py file with Android's system document picker.
- Run it with bundled Python 3.13.
- Stream print output and tracebacks into the in-app console.
- Cooperative STOP button.
- Pink interface designed for phones, tablets, and Quest's 2D Android app panel.

This is a normal Android 2D app, not an immersive OpenXR application. Only arm64-v8a is packaged. Only pure-Python scripts and packages supported by Chaquopy are supported out of the box. Run only scripts you trust.
